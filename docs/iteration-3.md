# Звіт по Ітерації 3

## Що зроблено
- Додано тестову стратегію і матрицю покриття.
- Підсилено тестованість через IClock та IErrorReporter (seams для моків).
- Розширено набір юніт- та інтеграційних тестів.
- Налаштовано coverage у локальному запуску та CI.

## Coverage
- Збір покриття: coverlet (opencover).
- Перегляд: reportgenerator (див. TESTING.md).
- Метрика coverage виводиться у CI Summary.

## Quality gate (CI)
- Build + тестування + збір coverage.
- Pipeline падає, якщо будь-який тест не проходить.

## Кількість тестів
- Unit tests: 36.
- Integration tests: 8.

## Усунені smells
- Прибрано приховану залежність від DateTime.Now (використано IClock).
- Відокремлено трасування помилок від бізнес-логіки (IErrorReporter).

## Що ще ризиковано перед Lab 37
- Відсутній реальний логер (лише console error reporter).
- Немає стійкої стратегії повторних спроб при I/O (тільки fail-fast).
- Немає перевірки конкурентних змін при паралельних збереженнях.
