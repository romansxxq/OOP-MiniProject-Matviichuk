# Питання для захисту та короткі відповіді

1. **Які рефакторинги були найважливішими перед релізом?**
   - Винесення консольних утиліт у ConsoleUI, покращення читабельності, XML-документація API.
2. **Чим FINAL_REPORT.md відрізняється від README.md?**
   - README — для запуску і огляду, FINAL_REPORT — для технічних рішень та компромісів.
3. **Які теми курсу демонструються найкраще?**
   - OOP, SOLID, патерни Strategy/Factory/Composite, LINQ, persistence, тестування.
4. **Що довелося добирати окремими розширеннями?**
   - Seams для тестів (IClock, IErrorReporter), додаткові стратегії валідації.
5. **Яке архітектурне рішення змінили б при старті?**
   - Можливе впровадження DI-контейнера для спрощення композиції.
6. **Як довести готовність до захисту?**
   - Пройти тестовий сценарій демо, показати тестування та документацію.
