# Release plan v1.0.0

## Scope v1.0.0
- Реєстрація пацієнтів, додавання лікарів і відділень.
- Запис на прийом з правилами (конфлікти часу, ліміт на день, статуси).
- LINQ-запити й базова аналітика.
- JSON persistence з відновленням стану.
- Консольний UI з розділенням утиліт.
- Тести, test-strategy, test-matrix, CI.

## Після курсу
- Підключення реальної БД або альтернативного сховища.
- Розширене логування (Serilog/NLog).
- Retry-політики для I/O.
- Ролі користувачів та авторизація.
- Розширене планування (довгі графіки, кімнати/кабінети).

## Допустимий технічний борг
- Консольний UI без DI-контейнера.
- Відсутність конфігураційних файлів для середовищ.
- Мінімальна локалізація повідомлень.

## Теми курсу: покриття
- Повністю: OOP, абстракції/інтерфейси, SOLID, патерни Strategy/Factory/Composite, LINQ, persistence, тестування.
- Частково: retry-політики, повноцінне логування, більш складні діаграми для UI.
- Розширення: in-memory репозиторії з Dictionary, test seams (IClock, IErrorReporter).
