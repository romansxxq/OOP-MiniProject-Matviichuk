# Звіт по Ітерації 1

## Виконані завдання:

1. **Ініціалізація проєкту та Git:**
   - Створено локальний Git-репозиторій для міні-проєкту.
   - Додано стандартний файл `.gitignore` для платформи .NET, щоб виключити з комітів скомпільовані файли (папки `bin`, `obj` тощо).
   - Зв'язано локальний репозиторій з віддаленим на GitHub.

2. **Формування ідеї системи:**
   - Вибрано предметну область: **Медична інформаційна система (MedCore)**.
   - Визначено головну мету програми: автоматизація процесу запису пацієнтів до лікарів на певний час із перевіркою конфліктів розкладу.

3. **Створення структури рішення (Solution):**
   - Створено головний файл рішення (`MedCore.slnx`).
   - Проєкт розбито на логічні модулі згідно з архітектурним підходом (Clean Architecture). Створено 5 окремих C# проєктів:
     - `MedCore.Domain` (Ядро системи, сутності)
     - `MedCore.Application` (Бізнес-логіка)
     - `MedCore.Infrastructure` (Робота з файлами/БД)
     - `MedCore.Console` (Інтерфейс користувача / Точка входу)
     - `MedCore.Tests` (Проєкт для юніт-тестів)

4. **Налаштування залежностей (References):**
   - Налаштовано правильні посилання між проєктами (наприклад, `Console` має доступ до `Application` та `Infrastructure`, а `Application` посилається на `Domain`).
   - Створено базові (порожні) класи та інтерфейси як заготовки для наступної ітерації.
