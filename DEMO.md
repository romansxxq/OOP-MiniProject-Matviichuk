# DEMO сценарій (3-5 хв)

## Підготовка
```bash
dotnet run --project src/MedCore.Console
```

## Кроки демо
1. **Старт програми**
   - Показати, що дані завантажуються з `data/medcore.json`.
2. **Ключовий сценарій: запис на прийом**
   - Реєстрація пацієнта: Ivan, Petrenko, CARD-100.
   - Додати лікаря: Olena Kovalenko, Therapist.
   - Створити відділення: Therapy, 2.
   - Призначити лікаря до відділення.
   - Створити запис на прийом на майбутню дату.
3. **Негативний сценарій**
   - Спробувати створити ще один запис на той самий час для того ж лікаря.
   - Очікувано: повідомлення про конфлікт часу.
4. **Збереження**
   - Виконати "Зберегти дані".
5. **Відновлення**
   - Перезапустити застосунок.
   - Переконатися, що дані завантажено.
6. **Пояснення архітектури**
   - Коротко показати шари Domain / Application / Infrastructure / Console.
   - Пояснити Strategy + Composite.
