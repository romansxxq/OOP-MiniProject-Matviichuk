# MedCore

Міні-проєкт для керування базовими процесами в лікарні: реєстрація пацієнтів, призначення лікарів до відділень, записи на прийом, пошук і аналітика.

## Основні можливості (Lab 35)
- Асинхронне збереження/завантаження стану у JSON (data/medcore.json).
- Мінімум 3 завершені use cases з бізнес-правилами.
- Strategy + Composite для розширюваної валідації записів.
- LINQ-запити, фільтрація, сортування та агрегована статистика.

## Швидкий старт

### Передумови

- .NET SDK 11.0 або новішої сумісної версії;
- Git для клонування репозиторію;
- Windows, Linux або macOS.

Перевірити встановлену версію SDK можна командою:

```bash
dotnet --version
```

### Розгортання та запуск

1. Клонуйте репозиторій і перейдіть до його каталогу:

	```bash
	git clone <URL_репозиторію>
	cd OOP-MiniProject-Matviichuk
	```

2. Відновіть залежності:

	```bash
	dotnet restore
	```

3. Зберіть рішення у конфігурації `Release`:

	```bash
	dotnet build --configuration Release
	```

4. Запустіть консольний застосунок:

	```bash
	dotnet run --project src/MedCore.Console
	```

Під час першого запуску програма завантажує дані з `data/medcore.json`, якщо цей файл існує. Для завершення роботи виберіть пункт `0`, а перед цим за потреби збережіть зміни через пункт `9`.

## Приклади використання

Після запуску доступне головне меню:

```text
1. Реєстрація пацієнта
2. Додати лікаря
3. Створити відділення
4. Призначити лікаря до відділення
5. Створити запис на прийом
6. Підтвердити запис
7. Скасувати запис
8. Запити та аналітика
9. Зберегти дані
0. Вийти
```

### Створення запису на прийом

Приклад послідовності дій для створення та підтвердження запису:

1. Виберіть `1` і введіть дані пацієнта, наприклад:
	- ім'я: `Олена`;
	- прізвище: `Коваль`;
	- номер медичної картки: `MC-001`.
2. Виберіть `2` і додайте лікаря:
	- повне ім'я: `Іван Петренко`;
	- спеціалізація: `Кардіолог`.
3. Виберіть `5` та введіть ID пацієнта, ID лікаря і дату, наприклад `2026-05-11 14:30`.
4. Запам'ятайте ID створеного запису та виберіть `6`, щоб підтвердити його.
5. Виберіть `9`, щоб зберегти результат у `data/medcore.json`.

Система перевіряє формат часу, конфлікти записів пацієнта та денний ліміт записів лікаря. Некоректні або конфліктні операції завершуються повідомленням про помилку без зміни даних.

### Пошук і статистика

1. Виберіть `8` у головному меню.
2. Для перегляду активних записів виберіть `1`.
3. Для розкладу лікаря виберіть `2` і введіть його ID.
4. Для пошуку пацієнтів виберіть `3` та введіть фрагмент імені або номера картки.
5. Для рейтингу лікарів виберіть `4` і вкажіть кількість результатів.
6. Для загальної статистики записів виберіть `5`.
