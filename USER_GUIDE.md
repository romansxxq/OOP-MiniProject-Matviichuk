# USER GUIDE

## Про програму
MedCore — консольна програма для базового обліку пацієнтів, лікарів, відділень і записів на прийом.

## Передумови
- Windows 10/11

## Як отримати програму
1. Відкрийте сторінку **Releases** у репозиторії.
2. Завантажте архів із програмою (zip) із секції **Assets**.
3. Важливо: **Source code (zip)** — це лише код, він не підходить для запуску.
4. Розпакуйте архів у зручну папку.
5. Усередині буде файл `MedCore.Console.exe`.

## Запуск
1. Відкрийте папку з `MedCore.Console.exe`.
2. Запустіть файл подвійним кліком.
3. Якщо Windows показує SmartScreen, натисніть **Докладніше** → **Виконати в будь-якому разі**.
4. У вікні консолі оберіть пункт меню та дотримуйтесь підказок.

## Дії в меню
- **Реєстрація пацієнта**: введіть ім'я, прізвище, номер медичної картки.
- **Додати лікаря**: введіть повне ім'я та спеціалізацію.
- **Створити відділення**: вкажіть назву і поверх.
- **Призначити лікаря до відділення**: вкажіть ID лікаря та ID відділення.
- **Створити запис на прийом**: вкажіть ID пацієнта, ID лікаря, дату та час.
- **Підтвердити / скасувати запис**: вкажіть ID запису.
- **Запити та аналітика**: активні записи, розклад лікаря, пошук пацієнтів, топ лікарів, статистика.

## Дані та збереження
- Збереження виконується через пункт меню **"Зберегти дані"**.
- Дані зберігаються у файлі `data/medcore.json` у папці програми.
- Під час запуску програма автоматично намагається завантажити цей файл.

## Поради щодо вводу
- Дата і час вводяться у форматі, який підтримує система (наприклад: `2026-05-22 14:30`).
- Для пошуку можна вводити лише частину імені або номера картки.

## Типові проблеми
- Якщо файл даних відсутній, програма стартує з порожнього стану.
- Якщо JSON пошкоджений, буде показано повідомлення про помилку.
- Якщо немає сторінки **Releases**, попросіть автора надати архів із програмою.
