# USER GUIDE

## Вимоги
- Windows.
- .NET Runtime 11.0 або .NET SDK 11.0.

## Швидкий старт (після збірки)
1. Відкрийте корінь проєкту.
2. Запустіть виконуваний файл:
   - Debug: `src/MedCore.Console/bin/Debug/net11.0/MedCore.Console.exe`
   - Release: `src/MedCore.Console/bin/Release/net11.0/MedCore.Console.exe` (якщо збирали Release)
3. Далі працюйте через меню в консолі.

## Якщо збірку ще не зроблено (одноразово)
```bash
dotnet restore MedCore.slnx
dotnet build MedCore.slnx
```

## Дії в меню
- **Реєстрація пацієнта**: введіть ім'я, прізвище, номер медичної картки.
- **Додати лікаря**: введіть повне ім'я та спеціалізацію.
- **Створити відділення**: вкажіть назву і поверх.
- **Призначити лікаря до відділення**: вкажіть ID лікаря та ID відділення.
- **Створити запис на прийом**: вкажіть ID пацієнта, ID лікаря, дату та час.
- **Підтвердити / скасувати запис**: вкажіть ID запису.
- **Запити та аналітика**: активні записи, розклад лікаря, пошук пацієнтів, топ лікарів, статистика.

## Збереження і відновлення
- Збереження виконується через пункт меню **"Зберегти дані"**.
- При старті програми виконується автоматичне завантаження з `data/medcore.json`.

## Поради щодо вводу
- Дата і час вводяться у форматі, який підтримує система (наприклад: `2026-05-22 14:30`).
- Для пошуку можна вводити лише частину імені або номера картки.

## Типові проблеми
- Якщо файл даних відсутній, програма стартує з порожнього стану.
- Якщо JSON пошкоджений, буде показано повідомлення про помилку.
