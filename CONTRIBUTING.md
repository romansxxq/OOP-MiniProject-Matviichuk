# Участь у розробці

Дякуємо за внесок у MedCore. Невеликі виправлення, документація, тести та нові функції вітаються.

## Робочий процес

1. Створіть fork репозиторію або отримайте доступ до робочого репозиторію.
2. Оновіть локальну гілку за замовчуванням:

   ```bash
   git switch main
   git pull --rebase origin main
   ```

3. Створіть окрему гілку для зміни. Використовуйте один із форматів:

   ```text
   feature/<короткий-опис>
   fix/<короткий-опис>
   docs/<короткий-опис>
   test/<короткий-опис>
   ```

   Наприклад: `feature/patient-search` або `fix/appointment-validation`.

4. Вносьте невеликі логічно завершені зміни та додавайте або оновлюйте тести, якщо це потрібно.
5. Перед створенням pull request перевірте стан проєкту локально:

   ```bash
   dotnet restore
   dotnet build --configuration Release
   dotnet test
   ```

6. Зробіть коміти з короткими описовими повідомленнями та опублікуйте гілку:

   ```bash
   git push -u origin <назва-гілки>
   ```

## Pull request

Перед відкриттям pull request переконайтеся, що:

- описано, яку проблему вирішує зміна;
- вказано основні технічні зміни та, за потреби, спосіб перевірки;
- додано або оновлено тести для зміненої поведінки;
- документацію оновлено, якщо змінилися команди або сценарії використання;
- усі локальні перевірки проходять без помилок;
- pull request має одну зрозумілу тему та спрямований у `main`.

Назва pull request має коротко описувати результат, наприклад: `Add patient search by medical card`.

Після відкриття pull request дочекайтеся завершення CI та врахуйте зауваження рецензентів. Необхідні виправлення вносьте в ту саму гілку.
